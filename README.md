# Python Fundamentals
A collection of Python projects and exercises built while teaching myself programming from scratch. These were written independently without tutorials or AI assistance — each one targeting a specific concept or skill.
# Projects
Task Manager
A task management system with email and password authentication. Users can add, delete, and mark tasks as complete. Built across two files using OOP with a login system, attempt counter, and full error handling.

Banking System
A terminal banking system with PIN validation, deposits, withdrawals, and transfers. Uses functions, logical operators, and if/elif control flow.

Battle Arena
A terminal combat game built with OOP class hierarchies and inheritance. Player and enemy classes with stats, attack methods, and a full game loop.

Fighter Database
An introductory OOP project using classes and subclasses to provide information about a fighter based on user arguments. First draft of object-oriented thinking.

Grade System
OOP project using a Student parent class and TopStudent child class. Inheritance, method overriding, and a custom __str__ dunder method with scholarship attribute.

Decorator Practice
A simple timer decorator that times a function counting to one million. Built to practise functional programming and the decorator pattern.
